# Customer Churn Prediction using Machine Learning

## Overview
This project builds a machine learning classification model to predict customer churn behavior using demographic and account-related features.

## Objectives
- Perform data preprocessing
- Handle missing values
- Encode categorical variables
- Train a classification model
- Evaluate prediction performance

## Tools & Libraries
- Python
- Pandas
- NumPy
- Seaborn
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## Machine Learning Workflow
1. Data preprocessing
2. Feature selection
3. Train-test split
4. Logistic Regression model training
5. Prediction and evaluation
6. Confusion matrix visualization

## Results
The Logistic Regression model successfully demonstrates binary classification workflow and predictive modeling fundamentals.

## Key Insights
- Passenger demographics strongly influence prediction outcomes.
- Logistic Regression provides an interpretable baseline classification model.
- Data preprocessing significantly impacts model performance.

## Conclusion
This project demonstrates foundational supervised machine learning concepts including preprocessing, model training, prediction, and evaluation using Python.
